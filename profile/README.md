### What is HBANK?

HBANK is a decentralized finance platform built on [Hedera](https://hedera.com). Swap HTS tokens, bridge assets cross-chain, and trade with low fees and fast finality.

### Features

- **Token Swap** — Trade HBAR and HTS tokens with aggregated liquidity from top Hedera DEXs
- **Cross-Chain Bridge** — Bridge assets between Hedera, Ethereum, Arbitrum and more via LayerZero
- **Missions & Rewards** — Earn rewards by completing on-chain activities
- **Portfolio Tracking** — Monitor your Hedera token balances and activity

### Built with

`Next.js` `TypeScript` `Hedera SDK` `LayerZero` `WalletConnect`
